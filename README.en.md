# Build your Android app with Kotlin and Compose, assisted by AI

Index of a three-unit online course (taught in Spanish). In each unit you build an Android app with Kotlin and Jetpack Compose, test-first, working with a coding agent while you review every diff and verify it with tests.

| Unit | Template | What you build |
| :--- | :--- | :--- |
| 1 | [`android-course-u1-rpg-quest`](https://github.com/ykro/android-course-u1-rpg-quest) | **RPG Quest & Dice Tracker**: modern Kotlin, Compose with Material 3, MVVM with `StateFlow`, coroutines, type-safe navigation and Koin. |
| 2 | [`android-course-u2-gallery-vault`](https://github.com/ykro/android-course-u2-gallery-vault) | **Gallery Vault** (offline-first art gallery): Retrofit, Room as the single source of truth, pagination, typed errors and Turbine. |
| 3 | [`android-course-u3-cloudboard-sync`](https://github.com/ykro/android-course-u3-cloudboard-sync) | **CloudBoard Sync** (collaborative board): Domain, UseCases and Data layers, Firebase Auth and Firestore, Security Rules and resilient retries. |

**Getting started:** open a unit template, choose **Use this template > Create a new repository**, give it your own name, make it **Private**, clone it, open its root in Android Studio and run `./gradlew testDebugUnitTest`. The challenge contract for each unit is in its challenge guide, in the course materials.

**Requirements:** a computer with at least 8 GB of RAM, stable Android Studio (bundles JDK 21), Git and a GitHub account, a coding agent; Firebase is optional.
